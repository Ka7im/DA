# Работа 1 Матрица расстояний

Цель работы — написать функции для трёх метрик, считать восемь наблюдений из Excel и проверить полученные матрицы. Каждое наблюдение содержит **две координаты**.

Код в lab1.py расположен в порядке пунктов задания. Перед каждым смысловым участком размещён поясняющий комментарий.

## 1 Функции формирования матриц расстояний

В начале программы определены функции в требуемом порядке:

| Функция | Формула для двух координат |
|---|---|
| manhattan_matrix(observations) | d = abs(xᵢ₁ − xⱼ₁) + abs(xᵢ₂ − xⱼ₂) |
| hamming_matrix(observations) | d = I(xᵢ₁ ≠ xⱼ₁) + I(xᵢ₂ ≠ xⱼ₂) |
| euclidean_matrix(observations) | d = √((xᵢ₁ − xⱼ₁)² + (xᵢ₂ − xⱼ₂)²) |

Здесь abs — модуль, а индикатор I равен 1 при выполнении условия и 0 в противном случае. Для Хэмминга используется число несовпадающих координат, как в разделе 2.2 приложенной теории. При двух координатах расстояние принимает значения 0, 1 или 2.

Каждая функция создаёт квадратную матрицу нулей, перебирает пары при j > i и записывает вычисленное расстояние в две симметричные ячейки. Главная диагональ остаётся нулевой. Для восьми наблюдений достаточно 28 вычислений расстояния на метрику. При двух признаках время работы составляет O(n²), память для результата — O(n²).

Матрица расстояний представляет начальные попарные различия между наблюдениями. В агломеративной иерархической кластеризации на этом шаге каждое наблюдение является отдельным кластером. Основание: «ИерархКласт для студ.docx», разделы 2.1 и 2.2.

## 2 Excel-файл и чтение наблюдений

Файл lab1.xlsx уже создан и включён в комплект работы. На листе «Наблюдения» записаны следующие целочисленные данные:

| Объект | x1 | x2 |
|---|---:|---:|
| P1 | -8 | 3 |
| P2 | 4 | -5 |
| P3 | 11 | 7 |
| P4 | -2 | 12 |
| P5 | 7 | 3 |
| P6 | -8 | -9 |
| P7 | 1 | -1 |
| P8 | 15 | -4 |

Все восемь точек различны и нерегулярно расположены в четырёх координатных четвертях. Диапазон первой координаты — от −8 до 15, второй — от −9 до 12. Целые числа позволяют проверить расстояния вручную. У отдельных пар совпадает одна координата, поэтому среди расстояний Хэмминга встречаются и 1, и 2.

Программа открывает существующий файл через load_workbook и считывает диапазон A2:C9:

- A2:A9 — метки наблюдений;
- B2:B9 — первая координата;
- C2:C9 — вторая координата.

Список observations первоначально пуст и заполняется только значениями из Excel. В Python нет заранее заданного списка исходных точек. Метки хранятся отдельно и не участвуют в вычислениях. Проверяются наличие меток, их уникальность и целочисленность обеих координат. Для контроля программа выводит считанные данные.

## 3 Вычисление и проверка матриц

После чтения данных программа вызывает три функции, выводит полученные матрицы и сравнивает все их элементы с независимо заданными контрольными матрицами. Контрольные матрицы в коде содержат ожидаемые расстояния для приложенного набора данных.

Проверены:

- размер каждой матрицы 8 × 8;
- нулевая главная диагональ;
- симметрия и неотрицательность;
- совпадение всех 64 элементов каждой матрицы с эталоном.

Для манхэттенского расстояния и Хэмминга сравнение точное. Для евклидова расстояния используется абсолютный допуск 10⁻¹². Его эталон задан через целые квадраты расстояний, из которых извлекаются корни.

Все **192 элемента** совпали с эталонами. Значения формул Excel дополнительно сверены с вычислениями Python. Фактический вывод запуска сохранён в results.txt.

### Ручная проверка

Для P2 = (4, −5) и P7 = (1, −1):

- Манхэттен: |4−1| + |−5−(−1)| = 3 + 4 = 7.
- Хэмминг: 1 + 1 = 2.
- Евклид: √((4−1)² + (−5−(−1))²) = √25 = 5.

Для P1 = (−8, 3) и P6 = (−8, −9):

- Манхэттен: |−8−(−8)| + |3−(−9)| = 0 + 12 = 12.
- Хэмминг: 0 + 1 = 1.
- Евклид: √(0² + 12²) = 12.

Дополнительные контрольные пары:

| Пара | Манхэттен | Хэмминг | Евклид |
|---|---:|---:|---:|
| P1 и P1 | 0 | 0 | 0 |
| P1 и P5 | 15 | 1 | 15 |
| P1 и P2 | 20 | 2 | √208 ≈ 14,4222 |
| P3 и P6 | 35 | 2 | √617 ≈ 24,8395 |
| P7 и P8 | 17 | 2 | √205 ≈ 14,3178 |

Готовые матрицы также расположены на листе «Матрицы» в Excel. Формулы используют только столбцы B и C листа с наблюдениями. Евклидовы расстояния отображаются с четырьмя знаками после запятой, без округления исходных результатов вычисления.

Если изменить набор наблюдений, программа рассчитает новые расстояния. Для проверки нового набора следует пересчитать и контрольные матрицы в пункте 3: текущие эталоны относятся к восьми точкам из таблицы выше.

## Запуск

Распакуйте архив в одну папку. Нужен Python 3.9 или новее. Выполните в терминале:

    python -m pip install -r requirements.txt
    python lab1.py

По умолчанию программа читает lab1.xlsx рядом с lab1.py. Другой путь можно передать первым аргументом:

    python lab1.py путь/к/файлу.xlsx

Для сохранения вывода выполните:

    python lab1.py > results.txt
